# OdooCNSh

Self-hosted Odoo hosting platform: Git branch = environment, deploy on push, multi-tenant
organizations and roles, staging cloned from production, golden template databases, idle sleep
and auto wake, backups (S3 / SFTP / WebDAV), live logs, monitoring, web code editor, Web Shell,
AI ops assistant and offline installation.

## Contents

- `odoocnsh/` – Odoo 20.0 module for the Odoo Apps Store (adds the *OdooCNSh* menu with the
  product overview; `static/description/` holds the store page, banner, icon and screenshots).
